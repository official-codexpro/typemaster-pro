# Car model asset

`spectral-gt-rs.glb` is the detailed sports car used for all five race drivers. The game clones the model and assigns each driver a separate paint color.

- Original asset: [Spectral GT RS](https://github.com/JaronKBragg7337/spectral-gt-rs)
- License: CC0 1.0 Universal; see `SPECTRAL-GT-RS-LICENSE.txt`.
- Model scale: meters; vehicle nose faces local `+X`.
- The game rotates the model into the circuit direction and animates its wheels.
